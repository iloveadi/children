# 🎨 어린이집 놀이 활동지 자동 생성기 (Children Activity Generator)

어린이집 및 유치원 교사를 위한 맞춤형 유아 놀이 활동지 웹 생성기입니다.
별도의 설치 없이 브라우저에서 바로 다양한 유아 활동지를 생성하고 실제 A4 용지에 꼭 맞게 인쇄할 수 있습니다.

## ✨ 주요 기능

1. **✏️ 이름 따라 쓰기**:
   - 깍두기 공책(원고지 격자 + 십자 점선 가이드)
   - 1행 검은색 본보기 글씨, 2행부터 흐린 회색 따라쓰기 글씨
   - 마지막 줄 스스로 쓰기(빈 칸) 옵션

2. **🈴 기초 한자 쓰기 (8급 숫자 1~10)**:
   - 1부터 10까지의 기초 숫자 한자 원클릭 선택
   - 4~5세 눈높이 사과(🍎) 개수 세기 카운팅
   - 큼직하고 시원한 깍두기 공책(84px × 84px) 중앙 배치

3. **🦋 반쪽 그리기 (대칭 그림 완성)**:
   - 좌우 대칭 공간지각력 및 창의력 미술 활동
   - 중앙 세로 점선 기준, 왼쪽 원본 라인아트와 오른쪽 백지 구성
   - 나비, 곰돌이, 로봇, 사과 도안 및 초급용 힌트 점선 옵션

4. **〰️ 운필력 선 긋기**:
   - 직선, 지그재그(꺾은선), 물결선(곡선), 혼합 난이도
   - SVG 두꺼운 둥근 점선 (`stroke-dasharray`, `stroke-linecap="round"`)
   - 귀여운 동물/탈것/우주 테마의 출발점 & 도착점 아이콘

5. **✂️ 싹둑싹둑 가위질 연습**:
   - 하단에서 상단으로 올라가는 세로 절취선
   - 가위 이모지(✂️) 시작점과 상단 목표물 도착점

6. **🔢 숫자 순서대로 점 잇기 (Dot-to-Dot)**:
   - 1부터 10까지 숫자를 순서대로 이어 그림 완성 (별, 집, 돛단배, 사과)
   - 1번 출발점 강조 및 초급용 힌트선 옵션

7. **⭐ 칭찬 스티커판**:
   - 아이 이름 맞춤형 목표 보상 배너
   - 10개 / 20개 / 30개 원형 스탬프 칸 및 GOAL! 특별 강조

8. **🖨️ A4 규격 완벽 인쇄 (`@media print`)**:
   - 인쇄 시 좌측 컨트롤 패널 및 회색 배경 자동 숨김
   - A4 용지 규격(`210mm × 297mm`)에 꼭 맞는 여백 없는 고화질 벡터 출력

## 🚀 사용 기술
- HTML5, CSS3, Vanilla JavaScript (단일 파일 실행 가능)
- SVG 벡터 그래픽
- CSS `@media print` 최적화
